## 一、项目说明（总览）

Vera 是基于 OpenClaw + Finance Suite MCP 技术栈打造的金融投研数字员工，7×24 小时在线。v2.0 阶段将底层架构从「工具集合+数据源+生成结果」升级为「Intent Layer → Workflow Runtime → Research Runtime → QC → Trust Gate → Evidence Bundle → Report Assembly」的**研究操作系统**，拆分为 7 个功能模块。

**核心护城河**：Trust Gate 三档可信契约 + Evidence Bundle 阻断字段机制，确保每个研究结论可追溯到证据、数据源、时间戳与允许用途（Allowed Use），从根本上解决 AI 幻觉与合规越界两大行业痛点。

**量化验证**：已完成 Research Runtime v0.8 smoke 全通过（5/5）、Trust Gate Contract v0 冻结、多渠道路由延迟 < 500ms、视频研报拆解准确率 94%。

## 二、场景痛点分析

### 投研人员面临的三大核心痛点

**痛点 1：数据源不稳定 → 单点故障即断服务**
- 现状：Wind API 故障频率约 2-3 次/月，每次故障导致 30-120 分钟服务中断
- 影响：投研团队需人工切换数据源，盘中关键时段（9:30-11:30、13:00-15:00）切换成本极高
- 用户反馈："早盘集合竞价最需要数据的时候，Wind 挂了就只能干等"

**痛点 2：盘中信息过载 → 人工整理难以 7×24**
- 现状：单个投研人员平均监控 50-80 只自选股，每日需处理：
  - 实时行情数据（分钟级）
  - 公司公告（日均 10-15 条/股）
  - 卖方研报（日均 3-5 篇相关研报）
  - 行业新闻（日均 20+ 条）
- 影响：人工整理耗时 2-3 小时/天，且易遗漏关键信息
