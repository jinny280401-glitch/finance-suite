# Vera Trust Gate｜可信数据链路说明

> **材料性质**：由《Finance Suite 信源手册》和《Finance Suite 数据信源解读手册》提炼的路演表达。  
> **技术边界**：不改变 Provider Runtime、Trust Gate、Evidence Bundle 或 Research Runtime 的现有规则；不新增数据源。

## 1. 一页路演版信源架构

### 核心命题

**AI 的可信，不是因为模型更聪明，而是因为每一个进入推理链路的信息都有来源、有状态、有使用边界。**

### 可信数据链路

```text
数据源
行情 · 财务 · 公告 · 新闻 · 研报
  ↓
Provider Runtime
统一接入 · 来源标记 · 质量状态 · 降级记录
  ↓
Trust Gate
判断证据能否使用，以及允许用于什么
  ↓
Evidence Bundle
保留来源 · 时间 · 验证状态 · allowed_use · blocked_fields
  ↓
Research Runtime / AI 输出
基于获准证据分析 · 结论关联证据 · 明示风险边界
```

### 三档 Provider 契约

| Provider 契约 | 业务含义 | 使用边界 |
|---|---|---|
| **REAL** | 真实数据源，可用于分析和生产研究 | 通过质量校验与 Trust Gate 后，按获准用途进入研究链路 |
| **FALLBACK** | 首选来源不可用时命中的降级数据 | 仅允许有限用途；必须显示降级来源，不得升级为完整生产证据 |
| **MOCK** | 用于验证系统链路的非真实研究数据 | 仅用于测试验证，不进入真实研究输出 |

> REAL、FALLBACK、MOCK 表示证据身份和使用权限，不是界面标签。任何来源缺失、内容缺失或用途越界的信息，都不能进入真实推理链路。

### Trust Gate 三个记忆点

| 记忆点 | 对应机制 | 对业务的意义 |
|---|---|---|
| **1. 来源可追溯** | `source provenance` | 每条证据都能回到实际来源、时间和命中路径 |
| **2. 结论可验证** | `evidence validation` | 研究结论能够关联证据，而不是只依赖模型表述 |
| **3. 风险可控制** | `allowed_use boundary` | 降级、缺失或受限证据只能用于获准场景，越界即阻断 |

### 页面收束金句

**传统 AI 先生成答案，再检查答案；Vera 先管理证据，再允许 AI 推理。**

---

## 2. 30 秒讲解稿

传统 AI 往往先生成答案，再判断它是否可信。Vera 把可信控制放在 AI 生成之前：数据先经过 Provider Runtime 标记实际来源和质量状态，再由 Trust Gate 判断这条证据能不能使用、允许用于什么。进入 Evidence Bundle 的每条证据，都保留来源、时间和用途限制。因此，Vera 的输出不是黑盒回答，而是来源可追溯、结论可验证、风险可控制的研究结果。

## 3. 与 Trust Gate PPT 页的对应关系

**对应页面**：`fig3-trust-gate-flow.html`｜当前 Deck Slide 7｜页面名称“Trust Gate”

| Trust Gate PPT 页面表达 | 本材料提供的支撑 | 现场讲法 |
|---|---|---|
| “先验证，再回答” | 数据在进入推理前依次经过 Provider Runtime、Trust Gate 和 Evidence Bundle | Trust Gate 不是回答后的检查，而是 Prompt 之前的可信控制 |
| 辨认来源 | REAL / FALLBACK / MOCK 三档 Provider 契约 | 先确认信息来自哪里、当前是什么状态 |
| 验证检查 | 来源、时间、完整度与证据有效性 | 不是“有数据就用”，而是先判断证据是否满足研究要求 |
| 判断可用边界 | `allowed_use` 与 `blocked_fields` | 同一条数据可以用于概览，不一定能用于生产研究或强结论 |
| 可验证、基础回答、承认模式、拒绝回答 | Trust Gate 根据证据状态选择表达强度 | 证据不足时降级、声明限制或拒绝，不把不确定性包装成确定性 |

### 与相邻页面的叙事衔接

- **上一页｜通用 AI vs Vera**：通用 AI 倾向于直接生成；Vera 先管理进入推理的信息。
- **本页｜Trust Gate**：说明来源、验证和用途边界如何在生成前生效。
- **下一页｜持续研究闭环**：可信控制不是一次性检查，而是在盘前、盘中、盘后的持续研究流程中重复执行。

## 口径边界

- 不将 REAL 表述为“绝对正确”；REAL 仍须经过质量校验和 Trust Gate。
- 不将 FALLBACK 表述为“与首选来源等价”；它只能进入获准的有限用途。
- 不将 MOCK 表述为研究数据；它不进入真实研究输出。
- 不宣称新增数据源、全数据覆盖或所有链路均已生产验证。
- 不把 Trust Gate 说成对最终答案进行事后打分；核心是生成前的证据准入和用途控制。
