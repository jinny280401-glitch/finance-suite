### 2. 定位重构：投研 Agent → **面向证券行业的 Agent 员工平台** ✅
- **决定**：Vera = 面向证券行业的 Agent 员工平台（正在构建证券行业的 豆包）
- **拒绝方向**：
  - ❌ 通用 Agent 员工（太泛，护城河不深）
  - ❌ 数字人 IP（偏离企业员工定位）
- **采纳方向**：
  - ✅ **面向证券行业的 Agent 员工平台**（身份层）
  - ✅ **Agent Trust Problem**（差异层）
- **核心叙事金句**：
  > "Vera 不是一个聊天工具，**她是一个能坐在投研工位上、把合规研报干完的数字员工**。投研只是她最擅长的事。"

### 3. 5 个非金融 Skill 的重新定位 ✅
- **原误解**：会冲淡金融主线
- **新定位**：是 Vera "代劳能力"的**演示样本**，不是产品边界
- **叙事逻辑**：「Vera 能代劳 5 件通用事→那她做金融只会更强→这就是护城河」
- **示范 Skill**：业务推进表/报销/会议记录/董事会/写稿

### 4. 三个 Demo 场景定稿 ✅

- **Demo 3 JIEZHU 情绪价值**：保留（投研人加班焦虑刚需）

### 5. 路演开场重新设计 ✅
