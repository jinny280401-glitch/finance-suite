## Q1：数据源挂了怎么办？

**标准答案**（1 分钟）：

Vera 走的是 4 层降级链：Wind（首选）→ Tushare Pro → JoinQuant → 东方财富。

主源挂掉的瞬间，< 500ms 自动切到下一家。降级期间系统会**自动收窄回答范围**——比如 Wind 挂掉切到东方财富时，从"深度研究"档位自动降到"基本面速览"档位。

关键不是"不挂"，是"挂了还能给用户透明反馈"——用户看到的每条数据都标了 FALLBACK 标签，知道"这个数据来源降级了，结论需要复核"。

**金句**：`挂了不可怕，挂了还说"我很准"才可怕。`

## Q2：跟豆包/ChatGPT 的核心差异是什么？

**标准答案**（1 分钟）：

**一句话差异：豆包能回答你问题，Vera 能替你干活。**

豆包、ChatGPT 这类通用 AI 是"对话能力"——你问它答，答完就走。

Vera 是"代劳能力"——你给它一个目标（写研报、做会议纪要、整报销单），它**真的把事干完**。

更关键的是金融行业的护城河：**Trust Gate**。豆包敢说"建议买入 8 成仓位"——这是违规的。Vera 会主动拒绝这种请求，因为它知道"哪些活不能干"。

**金句**：`更强的 Agent 满街都是，更可信的才是金融行业刚需。`

## Q4：合规性如何保证？会不会被监管处罚？

**标准答案**（1 分钟）：

Vera 的合规是**内嵌在系统里**，不是事后审查：

1. **Trust Gate 主动拒答越界**——短线建议/仓位/交易/资金流推断，触发后直接 blocked
2. **三档契约**（PRODUCTION/FALLBACK/MOCK）——数据可信度决定 allowed_use
3. **阻断字段**（_qc/raw/payload）——原始数据不进入 LLM 上下文
4. **免责声明**——每份报告底部明确"不构成投资建议"

**法律依据**：《证券投资顾问业务暂行规定》（证监会公告 [2010] 27 号）

**金句**：`不是不违规，是系统设计就不让它违规。`

## Q5：技术壁垒在哪？别人能不能复制？

**标准答案**（1 分钟）：

**三层壁垒**：

1. **数据壁垒**——Wind + Tushare + JQ + 东财四层降级，99.9% 可用性
2. **机制壁垒**——Trust Gate 三档契约 + Allowed Use 动态收窄
3. **方法论壁垒**——G 方法论（Field → Rule → Verdict）从年报/季报抽字段，不依赖 LLM

**关键不是 Skill 数量**，是"如何让 Agent 在金融场景下可信地干活"。

**金句**：`单个 Skill 能复制，方法论 + 数据底座复制不了。`
