```
┌─────────────────────────────────────────────────────────────────┐
│  数据流边界                                                      │
│                                                                 │
│  入站数据:                                                       │

│  │  POST /api/analyze → FastAPI → stock_data.py → AkShare   │   │

│  │                                                          │   │
```
