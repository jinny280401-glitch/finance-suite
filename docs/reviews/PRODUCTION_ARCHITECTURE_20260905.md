## 三、数据源降级链

```
┌────────────────────────────────────────────────────────────────┐
│                    数据源优先级                                   │
│                                                                │
│  Level 1: Wind API (万得)                                      │
│     ↓ (不可用时降级)                                            │
│  Level 2: Tushare Pro (积分制)                                  │
│     ↓ (不可用时降级)                                            │
│  Level 3: JoinQuant 聚宽 (jqdatasdk)                           │
│     ↓ (不可用时降级)                                            │
│  Level 4: AkShare (免费，无API Key)                             │
│     ↓ (不可用时降级)                                            │
│  Level 5: 同花顺 iFinD (SDK/HTTP双模式)                        │
│     ↓ (不可用时降级)                                            │
│  Level 6: 东方财富 Choice (EmQuantAPI)                         │
│                                                                │
│  辅助源:                                                        │
│  - SUPADATA (补充数据)                                          │
│  - Brave Search (网络搜索)                                      │
│  - Tavily Search (AI搜索, 多Key轮转)                            │
│  - Qwen LLM (通义千问, 分析生成)                                │
└────────────────────────────────────────────────────────────────┘
```
